# 평가 기준과 보고서 양식

열 명의 평가자가 모두 이 문서를 따른다. 평가자들은 가상 인물이며, 서로의 결과를 보지 않고 혼자 읽고 평가한다.

## 1. 객관성을 지키는 규칙
1. **혼자 읽는다.** 다른 평가자의 결과, 기획안, 교정 기록, 소개 페이지를 읽지 않는다.
2. **원고만 본다.** 평가 대상은 `원고/12부/` 열두 편이다. 작가의 말은 본문 평가가 끝난 뒤에 읽고, 따로 한 문단만 평가한다.
3. **근거를 댄다.** 모든 점수와 의견에 부 번호와 장면을 적는다. 인용은 2줄 이내로 한다.
4. **점수를 부풀리지 않는다.** 5점이 "출간된 소설의 평균"이다. 8점 이상은 같은 장르에서 손에 꼽을 수준일 때만 준다.
5. **장점 3개, 약점 3개를 반드시 쓴다.** 한쪽만 쓰면 무효다.
6. **자기 관점을 밝힌다.** 평가자의 위치(평론가·독자·작가) 때문에 생길 수 있는 치우침을 한 줄로 적는다.

## 2. 점수 기준 (1~10점)

| 점수 | 뜻 |
|---|---|
| 1~3 | 출간 수준에 못 미친다 |
| 4~5 | 평범하다. 출간된 소설의 평균 |
| 6~7 | 좋다. 분명한 장점이 있다 |
| 8~9 | 뛰어나다. 같은 장르에서 손에 꼽힌다 |
| 10 | 매우 드물다 |

## 3. 공통 평가 항목 (8개)

| # | 항목 | 묻는 것 |
|---|---|---|
| 1 | 몰입·가독성 | 다음 장을 넘기게 되는가. 멈춘 곳은 어디인가 |
| 2 | 인물 | 세 주인공과 주변 인물이 살아 있는가. 말투가 구별되는가 |
| 3 | 구성 | 세 줄기 교차편집과 12부 배치가 효과적인가 |
| 4 | 문장·대사 | 문장의 리듬, 대사의 맛, 상투어 |
| 5 | 주제 | "아랫사람의 말이 개 짖는 소리로 들린다"는 발상이 깊어지는가 |
| 6 | 현실성 | 사건과 디테일이 믿을 만한가. 인과가 맞는가 |
| 7 | 독창성 | 비슷한 작품과 무엇이 다른가 |
| 8 | 여운 | 다 읽은 뒤 남는 것이 있는가 |

**종합 점수**는 8개의 평균이 아니라 평가자가 따로 매긴다.

**출간 판단**은 셋 중 하나를 고른다: `지금 출간 가능` / `수정 후 출간` / `출간 어려움`

## 4. 보고서 양식

파일: `평가단/결과/NN_이름.md`

```markdown
# NN 이름 (분류 · 소개)

## 한 줄 평
(30자 안팎)

## 점수
| 항목 | 점수 | 근거 (부·장면) |
|---|---|---|
| 몰입·가독성 | /10 | |
| 인물 | /10 | |
| 구성 | /10 | |
| 문장·대사 | /10 | |
| 주제 | /10 | |
| 현실성 | /10 | |
| 독창성 | /10 | |
| 여운 | /10 | |
| **종합** | **/10** | |

출간 판단: 

## 장점 3
1.
2.
3.

## 약점 3
1.
2.
3.

## 내 관점의 핵심 의견
(에이전트 파일의 '관점' 항목에 답한다. 400~800자)

## 가장 좋았던 부 / 가장 약했던 부
- 좋았던 부: N부 — 이유
- 약했던 부: N부 — 이유

## 작가에게 고칠 것 하나
(가장 먼저 고쳐야 할 한 가지)

## 작가의 말
(한 문단)

## 내 치우침
(한 줄)
```

## 5. 종합 방법
- 항목별 평균과 최고·최저 차이를 낸다. 차이가 4점 이상인 항목은 의견이 갈린 곳으로 따로 표시한다.
- 세 명 이상이 같은 약점을 짚으면 **우선 수정 대상**으로 올린다.
- 평론가·독자·작가 세 그룹의 평균을 따로 낸다. 그룹 사이 차이가 작품의 성격을 보여 준다.
- 결과는 `평가단/결과/종합.md`와 배포 페이지 `review.html`에 반영한다.
