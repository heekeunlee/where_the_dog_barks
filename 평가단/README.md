# 가상 평가단

《어디서 개가 짖는구나》를 열 명의 가상 평가자에게 읽히고, 서로 영향받지 않은 평가를 모으기 위한 설정이다.
평가자는 모두 지어낸 인물이며 실존 인물과 관계가 없다.

- 소개 페이지: https://heekeunlee.github.io/where_the_dog_barks/review.html
- 평가 기준과 보고서 양식: [평가기준.md](평가기준.md)
- 평가자 정의(Claude Code 서브에이전트 형식): [agents/](agents/)
- 결과: [결과/](결과/) — 2026-10-04 1차 평가 완료, 종합 6.75/10, 전원 "수정 후 출간" ([종합.md](결과/종합.md))

## 실행 방법
1. 이 저장소에서 Claude Code를 연다.
2. 서브에이전트로 쓰려면 `agents/` 파일을 `.claude/agents/`에 복사한다. (`.claude/`는 gitignore 대상이다.)
   ```bash
   mkdir -p .claude/agents && cp 평가단/agents/*.md .claude/agents/
   ```
3. "가상 평가단 10인으로 평가 진행해"라고 요청한다. 열 명이 동시에, 따로 원고를 읽고 `결과/`에 보고서를 남긴다.
4. 마지막에 `결과/종합.md`를 만들고 `review.html`의 결과 표를 채운다.

## 객관성 장치
- 평가자끼리 결과를 보지 않는다.
- 기획안·교정 기록·소개 페이지를 읽지 않고 원고만 읽는다.
- 5점이 출간작 평균이다. 모든 점수에 부·장면 근거를 단다.
- 장점 3개와 약점 3개를 반드시 함께 쓴다.
