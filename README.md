# 어디서 개가 짖는구나

3부 연작 장편소설 기획 저장소. 직장인의 희노애락을 블랙코미디와 휴먼드라마로 다룬다.

> 대기업 사무실에서 주말에 쓰인 기획서 한 줄이 협력사로, 다시 야간 창고로 떨어지는 동안,
> 아래에서 올라온 말은 전부 개 짖는 소리로 들린다.

## 개요

| | |
|---|---|
| 장르 | 오피스 블랙코미디 · 휴먼드라마 (마술적 리얼리즘 장치 1개) |
| 구성 | 32화 3부 · 약 105,000자 |
| 판형 | 신국판 POD · 본문 약 195~205p |
| 독자 | 25–45세 재직자 |

## 3부 구조 — 먹이사슬 릴레이

세 부를 하나로 묶는 것은 인물이 아니라 **한 문장**이다.

| 부 | 무대 | 화수 | 가해자 | 핵심 공포 |
|---|---|---|---|---|
| 1부 | 대기업 — 묵산그룹 전략기획본부 15층 | 12화 | 시스템 (얼굴이 없다) | 절차가 다 지켜졌는데 아무도 책임지지 않는다 |
| 2부 | 중소기업 — (주)율목정밀, 직원 9명 | 10화 | 사람 (사장 얼굴이 보인다) | 쓰는 순간 누군지 특정된다 |
| 3부 | 알바·취준 — 야간 물류창고 + 취업준비 | 10화 | 없음 (관계 자체가 없다) | 말을 들어줄 상대가 애초에 없다 |

1부의 기획서 3장 2절("2차 협력사 단가 8% 재협상 · 납기 5일 단축")이 2부로, 2부의 단기인력 투입 결정이 3부로 떨어진다.

3부는 **낮(취준) / 밤(알바) 교차** 구성이다. 취준생과 알바생은 대부분 같은 사람이기 때문이다.

## 1부 부조리 6종

밀실 스릴러 기계에만 기대면 독자가 겪어본 일이 없어 공감이 얕아진다.
여섯은 따로가 아니라 하나의 인과 사슬이다.

```
① 못 알아듣는다 · 들키면 안 된다
     ↓
② 트집으로 방어한다 (무한 후퇴)
     ↓  결정하면 책임진다
③ 결정을 회피한다 ("이따위 보고로 뭘 결정하란 말입니까")
     ↓  결정을 안 하니 시간이 결정한다
④ 근원 없는 지시 ("전면 수정 요망")
     ↓  부장이 반박하면 팀이 보복당한다
⑤ 부장이 삼킨다 ("확인 후 보고드리겠습니다")
     ↓  그 확인이 팀의 주말이 된다
⑥ 아무도 결정하지 않은 숫자가 확정되어 있다 (7.6 → 8)
     ↓
   2부의 야간 특근 · 21화의 사고
```

**짖음이 걸리는 조건이 특정된다 — 책임이 발생하는 문장에 걸린다.**
3부에 짖음이 거의 없는 이유도 이것이다. 책임질 사람이 없으면 걸릴 데도 없다.

**239장은 아무것도 하지 않고, 한 줄이 사람을 다치게 한다.**

## 다루는 계층

네 집단 위에 세 계층을 더 얹되, **화수를 늘리지 않고 기존 화에 심는다.**

| 계층 | 인물 | 위치 |
|---|---|---|
| 대기업 정규직 5직급 | 이강토~장독고 | 1부 |
| **파견 계약직** | 정수경 34 | 1부. 익명 앱 가입 불가 = 짖을 수조차 없다. 복원할 기록조차 없다 |
| 중소기업 사장~신입 | 구본철~김단 | 2부 |
| **이주노동** | 응우옌 반 남 34 | 2부. E-9 4년차 |
| 단기 알바 | 야간 3조 | 3부 |
| **플랫폼 노동** | 남해인 이력 | 3부 26화. 근로자가 아니라 산재가 안 됐다 |
| 취업준비 | 남해인 25 · 스터디 6인 | 3부 낮 |

## 스침 설계

세로축이 인과(한 문장이 아래로 떨어진다)라면, 가로축은 스침이다.
네 계층이 서로를 모른 채 아홉 번 지나간다. 남해인은 1부 시점에 이미 존재하며,
묵산타워 지하 편의점 야간 알바였다. **거기서 일하다가 그 회사에 가고 싶어졌다.**

핵심은 ② → ⑧ → 32화 한 묶음이다. 1부 7화에서 김민지가 새벽 커피를 사며
"감사합니다"에 대답한다. 3부 28화 면접에서 그녀는 그를 기억하지 못한다.
32화에서 그녀가 그의 이름을 타이핑한다.

## 핵심 장치 — '짖음' 현상

권력 아래의 사람이 시스템에 불편한 진실을 말하면, 듣는 쪽 귀에만 개 짖는 소리로 들린다.

- **R1 도달 실패** — 말한 사람은 모른다. 같은 대화를 두 사람이 다르게 기억한다.
- **R2 기록 소실** — 짖음으로 들린 말은 문서에서 미끄러진다. 글자는 있고 눈이 지나친다. *(플롯 엔진)*
- **R3 전염과 상승** — 아랫사람 말을 짖음으로 처리한 자는 자기 말도 윗선에게 짖음으로 들린다. *(블랙코미디)*
- **R4 해제** — 듣는 쪽이 말하는 쪽의 이름을 부르는 순간만. 지속되지 않는다. *(휴먼드라마)*

현상의 원인은 끝까지 설명하지 않는다.

## 원고 조판

```bash
python3 tools/md2pdf.py 원고/1부/01_퇴근_20분_전.md   # 한 화
python3 tools/md2pdf.py --merge 원고/1부/*.md         # 부 단위 합본
```

신국판 152×225mm, 나눔명조 10.5pt, 행간 1.9, 왼끝맞춤. 결과는 `원고/pdf/`.
한국어는 브라우저가 자간이 아니라 공백만 늘리므로 양쪽정렬을 쓰지 않는다.
