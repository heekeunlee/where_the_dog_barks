# 어디서 개가 짖는구나

12부 교차편집 장편소설. 직장인의 희노애락을 블랙코미디와 휴먼드라마로 다룬다.

> 대기업 15층의 주말 62시간, 화성 협력사의 한 달, 야간 물류 라인의 7주.
> 세 시간선이 한 문장으로 이어지는 동안 아래에서 올라온 말은 전부 개 짖는 소리로 들린다.
> 그리고 그 말을 처음 한 사람은 자기 목소리마저 그렇게 듣게 된다.

## 짖음 규칙 — 넷과 하나

아래 사람이 불편한 진실을 말하면 **듣는 쪽 귀에만** 개 짖는 소리로 들린다. 원인은 끝까지 설명하지 않는다.

- **R1 도달 실패** — 말한 사람은 전달됐다고 믿는다. 같은 회의를 둘이 정반대로 기억한다.
- **R2 기록 소실** — 회의록에서 그 줄만 미끄러진다. 김민지의 매크로 「정음」을 거치면 읽힌다.
- **R3 전염과 상승** — 아래 말을 짖음으로 처리한 사람은 위에서 자기 말도 짖음으로 들린다. **빌런도 짖는다.**
- **R3+ 끝** — 사다리 꼭대기에서는 자기 목소리도 짖음으로 들린다.
- **R4 해제** — 이름을 부르고 그 자리에 잠깐 자기를 놓아 볼 때만 풀린다. 지속되지 않는다. **가장 낮은 자리에서 먼저 풀린다.**

## 조판

```bash
python3 tools/md2pdf.py 원고/12부/01_랜선_뽑아.md   # 한 부
python3 tools/md2pdf.py --merge 원고/12부/*.md      # 전체 합본
python3 tools/make_book.py                          # 완성본 (속표지 · 차례 · 12부 · 작가의 말)
```

신국판 152×225mm, 나눔명조 10.5pt, 행간 210%, 양쪽맞춤(음절 단위 줄바꿈). 한 행 32자 · 한 면 24행.
무선제본을 감안해 여백은 안쪽 19mm / 바깥 14mm로 좌우 면을 뒤집는다. 고딕은 나눔고딕(Type3 회피).
부 도비라는 두지 않고 각 부의 첫 면 위를 46mm 비운다. 작가의 말은 백면을 끼워 오른쪽 면에서 시작한다.
의존: Chrome 헤드리스 · PyMuPDF.
